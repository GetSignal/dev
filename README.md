# dev
A TikTok-style, short-video app targeting rapid, smooth playback and a "For You" (FYP) experience.

## Android Build Flags
- For Android-specific build flags (API_BASE_URL, ENABLE_LONG_PRESS_SCRUB) and debug HTTP cache logging, see `signal-android/README.md`.

## iOS Runtime Flags
- For iOS environment variables (API_BASE_URL, ENABLE_LONG_PRESS_SCRUB, ENABLE_DEBUG_SEEK) and how to set them in Xcode or CLI, see `signal/signal/README.md`.
